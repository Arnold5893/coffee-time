## 1. 引言

### 1.1 目的

为第一版开发提供可编号、可验收、可追溯的需求基线，供 AI/Agent 按规格实现与测试。

### 1.2 术语

继承设计方案词汇：基底线、帮工会话、模态对话、判定步、缺步、偏差、错误率、四档评价、饮用人数、浸泡、通关卡片。新增术语经 `/domain-modeling` 进入 `GLOSSARY.md`。

## 2. 总体描述

### 2.1 产品定位

第三人称单人 3D 咖啡店体验游戏。核心命题："有一天，我推开朋友那家店的门，坐了一下午。"主线是待着，帮工是自愿插曲，一天以打烊收尾。不做联机。

### 2.2 用户与环境约束

- 开发者：单人，无 Unity 经验，全部代码由 AI/Agent 生成。
- 引擎：Unity 6000.0 LTS + URP。
- 平台基线：Windows 10 64-bit+；Android API 29+；**iPad 不在首版范围**（无 Mac，见 FSR 2.2）。
- 测试设备：开发 PC（i7-14650HX / RTX 4060 Laptop / 32GB）、小米 14（Android）。注意：两台均为高性能设备，其达标不代表中低端设备达标，此为已记录局限。
- 每周投入 10–15 小时；1 个月竖切里程碑，无硬性截止。

### 2.3 假设与依赖

- 老板形象、店铺素材、真实菜单已获授权。
- 音乐首版使用免版权占位曲目。
- 角色与场景资产以免费资产改造为主。
- 依赖设计方案 v4 不再发生结构性变更；若变更，本文件随版本号同步修订。

### 3.6 做饮品系统（FR-MAKE，来源：设计方案 §7.1–7.7）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-MAKE-01 | 每杯饮品由一串固定步骤组成，步骤可跳过、可提前出杯；不模拟压粉力度、奶泡质地、水流轨迹；不做奶泡表现 | P0 |
| FR-MAKE-02 | 同一配方数据支持手动（玩家，逐步操作并记录偏差）与自动（老板，动画＋计时无偏差）两种驱动，配方只写一份 | P0 |
| FR-MAKE-03 | 五种操作原语：按住、点击、选择、放置、等待；PC 与移动端操作一致 | P0 |
| FR-MAKE-04 | 四条基底线：美式线、拿铁线、无咖啡线、茶线，步骤与判定按设计方案 7.4 | P0（拿铁线）/ P1（其余三条） |
| FR-MAKE-05 | 单杯步骤数 6–9 步，耗时约 15–30 秒；顺序为推荐而非强制 | P0 |
| FR-MAKE-06 | 搅拌为"放置即触发"：搅拌棒移至杯附近自动搅拌，完成自动归位 | P1 |
| FR-MAKE-07 | 萃取为自动等待过程，无判定；液流停止后才能取杯 | P0 |
| FR-MAKE-08 | 茶线：取茶罐 → 倒茶叶 → 注水 → 浸泡（壶上进度条）→ 整壶＋玻璃小杯上托盘；浸泡不会超时，可中途走开做别的单 | P1 |
| FR-MAKE-09 | 茶罐为透明玻璃罐，茶汤颜色按茶种区分；浸泡时长是茶罐间唯一手感差异 | P1 |
| FR-MAKE-10 | 风味/修饰维度：稀释、风味、温度、搅拌、饮用人数；所有 SKU 差异落在这五个维度，不产生新步骤模板 | P1 |
| FR-MAKE-11 | 饮品出杯形态：咖啡单杯；茶为整壶＋按饮用人数配 1–2 只玻璃小杯 | P1 |

### 3.7 步骤评价（FR-EVAL，来源：设计方案 §7.9）

| 编号 | 需求 | 优先级 |
| --- | --- | --- |
| FR-EVAL-01 | 判定口径：只统计有判定的步骤；错误率 = 错误步数 ÷ 判定步数；缺任一必需步骤直接判"非常差" | P0 |
| FR-EVAL-02 | 四档阈值（好/一般/差/非常差）按设计方案 7.9.6 错误率表执行，可按饮品单独覆盖 | P0 |
| FR-EVAL-03 | 有判定步骤出现偏差时给予即时反馈（音效、液面颜色、器具动作幅度），不显示文字评级；玩家可选重做该步或带偏差继续 | P0 |
| FR-EVAL-04 | 系统门槛（萃取未完不可取杯、茶未泡好不可上托盘）只禁止操作，不判错 | P0 |
| FR-EVAL-05 | 评价者规则：老板空闲（未在制作）时当场评价；老板在制作时不评价，由顾客在交付时按同一档位评价 | P0 |
| FR-EVAL-06 | 老板四档反应按设计方案 7.9.7：好档 70% 概率夸奖、差档必定指出、非常差必定给出"重做这杯/交给老板做"选择；老板不接受缺步成品 | P0 |
| FR-EVAL-07 | 顾客四档反应按设计方案 7.10.3；非常差时给出"重做/就这样"选择；顾客可接受缺步成品 | P1 |
| FR-EVAL-08 | 同一档位连续出现时换用更短台词；同款饮品连续两杯错在同一步时台词点名该步 | P2 |
| FR-EVAL-09 | 不惩罚：不扣分、不扣钱、不影响进度；客人不因饮品差离店 | P0 |
