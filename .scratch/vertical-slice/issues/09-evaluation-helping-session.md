# 09: 评价与帮工会话

**What to build:** 吧台"帮老板做杯咖啡"入口 → 挑单对话（老板问"你想做哪个？"，给 2–4 个拿铁线饮品选项，可单选/多选/全选，不显示订单列表）→ 锁定不可更换 → 逐单制作 → 每杯出杯时若老板空闲则当场四档评价（模态）：好 70% 概率夸奖、一般中性动作、差必指出、非常差给出"重做这杯/交给老板做"；缺步成品老板不接受。所选全部交付后帮工结束，无结算界面。

**Blocked by:** 06 做饮品系统（领域层）、07 吧台近景与做饮品 UI、08 模态对话

**Status:** ready-for-agent

- [ ] 挑单在对话内完成，2–4 选项，无列表界面（FR-HELP-03）
- [ ] 锁定后不可更换/退出（FR-HELP-05、FR-HELP-07）
- [ ] 四档评价按错误率与缺步触发（FR-EVAL-02/06）
- [ ] 非常差两选项可用：重做/交给老板（FR-EVAL-06）
- [ ] 未选订单转老板处理（FR-HELP-04）
- [ ] 帮工结束无结算界面（FR-HELP-06）
