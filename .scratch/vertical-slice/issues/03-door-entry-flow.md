**A. 门外地台（Blender 源，`build_shop.py`）**

- 新增 `Porch` 对象：入口墙段外挑 **3.00m 深 × 1.85m 宽**，顶面与室内地面齐平（`z=0`），厚 0.15m。
- 宽度正好等于入口那段墙：入口在右下的凹口里，往西再多就压进吧台区了，所以不再对称外扩。
- 只做地台，不做外立面（用户拍板）。材质 `M_PORCH`（`porch_paving`，0.44 灰、粗糙 0.85）。
- 地台边缘没有可见护栏，但**三面加了不可见碰撞围挡**（见 C），玩家不会从平台边缘掉进空场景。

**B. 门（Blender 源）**

右下入口拆成 4 件，左上常闭门保持 1 件：

| 对象 | 内容 | 是否烘碰撞体 |
| --- | --- | --- |
| `Door_entrance` | 木门框 + 两侧墙垛 + 门头上方白墙 + 「安全出口」灯箱（环形网格） | **否**（会把门洞封死） |

| `Door_entrance_Panel` | 门西侧那条固定窄亮子 0.40 宽（照片里门旁那条） | 是 |

- seg6（入口侧墙）材质由木饰面改成白墙：它现在是门外的可见面，照片里门两侧都是白墙。

**C. 碰撞体与分层（`ProjectSetup.cs`）**

- **门框不烘碰撞体**：门框是"环形"网格（两侧立框 + 门头上方白墙），按整体包围盒烘一个 box 会把整个门洞封死 —— 上一版最直接的卡点，玩家走到门前 0.38m 就再也推不动了。`skipExact = { "Door_entrance" }`。
- **左上常闭门反过来必须烘**：它本来就是整体一件，烘出来的 box 正好把门洞堵死，玩家撞得上去、进不去。
- 新增自定义层 **`Boundary`（层 8）**，由 `EnsureLayer()` 写进 `ProjectSettings/TagManager.asset`。门外三面围挡挂在这一层：
  - 角色会撞上（CharacterController 不看层）；
  - **交互射线和镜头避让都跳过它**（`~LayerMask.GetMask("Boundary")`），否则一道看不见的墙会把"点门"和第三人称镜头全挡住。

**D. 玩家与出生点**

- 出生点在**门外地台**上：`doorCenter - 门法线 × 1.75m`，朝门站。
- 门法线与门洞范围都从**门槛条**读：中心 = 门洞中心，较长的一条水平边 = 净宽 1.50m。
- 法线正负**不用包围盒中心猜**（店面是 L 形多边形，上一版这么算出来是斜的 `(-0.91, 0.40)`），改成"从门外地台中心指向门心"的那一侧就是店内方向 —— 地台本来就在门外，这个方向是构造出来的、不会错。
- `Porch` 不再计入店面取景包围盒（`renderers.Where(r => r.name != "Porch")`）。
- 店内另设 `InteriorAnchor`：从店面中心向外螺旋找一块不压家具的空位（`r=0.6m, ang=90°`），供 02 票的跟随镜头验收图取景与移动冒烟测试做锚点。

**E. 门的运行时逻辑（`Assets/Scripts/Interaction/EntranceDoor.cs`）**

- 状态机 `Closed → Opening → Open → Closing → Closed`：
  - `Opening` / `Closing` 期间不接受新点击（重复点击无副作用），其余状态都可以；
  - `Open` 时若玩家越过门槛 `enterDepth = 0.55m` 记 `HasEntered` 并转 `Closing`；
  - `Closing` 时若玩家还卡在门洞里（前后 0.40m、横向在门宽内）立刻转回 `Opening`，不夹人。
- 门扇绕**世界 Y 轴**用 `Quaternion.AngleAxis(θ, Vector3.up) * closedRot` 旋转（不用 local 轴：FBX 子物体带 100 倍缩放、根节点绕 X 转了 -90°，局部轴不等于世界轴）。开 **92°**、**向店外**摆（平面图的门弧画在外侧，且门内东侧紧贴阳光区长桌，往内开会撞桌子）。0.60s 开、0.90s 关。
- 开合方向**不写死正负号**：`SwingSign()` 把门扇自由边分别转 ±90°，取"背向店内"的那个符号。
- 交互射线：光标锁定时从屏幕中心、未锁定时跟鼠标；命中门扇/固定亮子/门槛碰撞体即开门。门扇与亮子之间留了几厘米缝，正对缝隙时射线会直接穿过去打到店内地面 —— 兜底：只要门平面交点比命中的东西更近、且交点落在门洞矩形内（净宽 × 2.35m 高），也算点到了门。
- `rayRange = 8m` 是射线长度（第三人称镜头在角色身后 3.6m，用 4.5m 够不到），`playerReach = 2.6m` 单独判"人站在门口附近"。

**F. 门铃（`Assets/Scripts/Audio/ProceduralSfx.cs`）**

- 仓库里没有任何音频资产，门铃用程序化合成：E6(1318.5Hz) → A5(880Hz) 两声，各自带 2× / 3× 泛音、指数衰减 7.0，总长 1.3s，首尾 8ms 淡入淡出防爆音。`AudioClip.Create` 运行时生成，不落盘。
- 相机补了 `AudioListener`（之前没有，会一直刷 "no audio listeners"）。
- 12 票接正式音效时把 `ProceduralSfx.DoorBell()` 换成 `AudioClip` 资产即可，调用点不动。

**G. 零引导**

- 进店后不弹任何 UI、箭头、任务提示，门关了就是关着。`EntranceDoor` 不持有任何 UI 引用。
- 左上那扇常闭门也不给任何提示 —— 撞上去就是撞上去。

## fix-07：阳光区长桌在 12 号凳后收头，门前留出落脚区

**问题**：上一版把东窗那段阳光区长桌做满了整段墙（py 600→1180），一直顶到主入口门洞，
占掉门洞东侧 0.30m。平面图上桌尾其实收在 12 号吧凳下面一点（py≈1040），门口前留出约 1.8m。

**改法**（`仅供参考的文件/build_shop.py`）

```python
COUNTER_END_PY = 1040
COUNTER_LEN = {4: (COUNTER_END_PY - 600) * S}     # 只对东窗那段生效
```

- `build_window_wall()` 新增 `counter_len` 参数：桌面 / 挡板 / 前面板 / 暖气格栅 / 插座都按这个长度收；
  窗框、玻璃、斑马帘仍然走满整段（窗是整面窗，桌只是家具）。
- 桌尾补了一块 `M_WOODP` 封板（`cl-0.03 .. cl`，深度 0..0.42，高 0..1.04），否则从门口看进去是个空心的开口盒子。
- 桌尾之外的暖气格栅/插座跳过：`if tm + 0.42 > cl: continue`。
- 斜窗那段（seg2，1–6 号凳）不动，仍做满。
