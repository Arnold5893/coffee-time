# 03: 进店流程

**What to build:** 开局玩家在店门外（门廊区）。走到门前点击门 → 开门动作＋门铃音效（占位）→ 玩家自己走进店内 → 门自动关闭。进店后无任何引导、箭头、任务提示。进入流程状态机：门外→点击门→门开→玩家进入→门关。

**Blocked by:** 02 玩家移动与镜头

**Status:** ready-for-agent

- [ ] 门外有出生点与可站立的门廊区
- [ ] 点击门触发开门动作与门铃（FR-INIT-05）
- [ ] 进店由玩家移动走完，不是过场动画
- [ ] 进店后零引导（FR-INIT-06）
- [ ] 门状态机转换正确，重复开关无异常
