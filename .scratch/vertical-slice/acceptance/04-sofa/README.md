# 04 补完 · 双人沙发一椅两座

04 票当初只接了 33 个座位（吧台 3 / 阳光区 12 / 圆桌 12 / 会议桌 6），把「一件家具两个座位」的沙发留成了尾巴。
这一轮补上：店内 10 张双人沙发，各出 **2 个座位**，座位总数 33 → **53**。

## 怎么做的

新增配置字段 `lateralOffset`（沿坐者左右方向偏移多少米，正数朝右手边）：

```json
{ "id": "sofa-g1-a-1", "zone": "sofa", "kind": "sofa", "anchor": "Group_Sofa_1_-1",
  "faceTarget": "Group_Table_1", "seatHeight": 0.44, "surfaceForward": 0.45, "lateralOffset": -0.30 }
```

- 一个 `anchor` 出两条座位记录，`lateralOffset` 取 ∓0.30，正好落在两块坐垫中心
  （`build_shop.py` 的 `loveseat` 里坐垫就在 `(k-0.5)*0.6`）。
- 方向不读对象自身 X 轴：FBX 根节点带 -90°X，局部轴和世界轴对不上。改用**已经算好的朝向**推左右：
  `lateral = (facing.z, 0, -facing.x)`（= up × facing）。家具换朝向不用改数值。
- 校验加了上限 ±0.65m（再大就偏到沙发外面去了）。

## 踩到的两个坑

1. **20 个沙发位全部「原地起立」**：站位默认是"正后方 0.55m"，减去探测胶囊半径 0.28 只剩 0.27m，
   而双人沙发背框在 -0.32m —— 被自己挡住。沙发是更深的家具，默认站位改到 **0.66m**
   （0.66-0.28=0.38 越过背框，同时仍守住"站位不超出座位 0.70m"的既有约束）。
2. **「离 3m 远不提示」误报**：那条用例原来取"吧凳正后方 3m"，沙发位接进来后这个点正好贴着别的座位。
   改成绕一圈找一个离**所有**座位都够远的空地再断言。
