- 玩家站位与原地近景镜头的取景范围是否覆盖全部工位
- 茶罐架、进度条显示位置的空间预留
- 若 02 结论为"废弃重建"，本票同时承担全店灰盒的方块布局验证

输出：灰盒场景截图＋布局定案（含任何对设计方案 12.3 的调整建议）。

## 完成标准

## Comments

### 2026-11-06 实测核对（证据：import-test/bar_layout_review.png）

九工位核对结果（设计方案 12.3）：

| 工位 | 现状 |
| --- | --- |
| ① 点单/收银 | ✅ Cashier 位于前柜台面 x≈3.06，面向顾客侧 |
| ② 浓缩咖啡机 | ✅ 后柜台面 x 2.86–3.67 |
| ③ 磨豆机位 | ✅ 双磨豆机＋压粉器 后柜台面 x 1.90–2.86 |
| ④ 茶罐架 | ❌ 需新增；后柜东段有 ~1.8m 空闲台面（x 5.9–7.7）可放 |
| ⑤ 注水/茶壶位 | ❌ 需新增；同上空位，进度条悬浮位置预留 |
| ⑥ 出杯台 | 可共用前柜西段台面（收银左侧），无需新增家具 |
| ⑦ 搅拌工位 | 可放后柜杂物区（1.8m，重整后腾出）；搅拌棒归位点挂后柜 |
| ⑧ 托盘存放点 | ❌ 需新增；后柜东段台面下或台面一角 |
| ⑨ 玩家站位与移动路径 | ⚠️ **阻塞问题：前后柜台通道仅 0.32m（y 0.75–1.07），玩家无法进入吧台内侧** |

其他实测：主入口 x 7.82–9.38 y≈1.7（右下侧，贴吧台东端，与设计方案一致）；顾客路径 进门→前台点单 动线顺畅；前柜顾客侧有 3 个吧台凳。

**待 Arnold 决策**：玩家制作饮品时站哪里？

- 方案 A：玩家站顾客侧（前柜前），操作以 UI 原语驱动（点击/按住工位图标），镜头原地近景对准后柜工位。与设计方案 7.3 的原语体系一致，零场景改动；代价是"站进吧台"的代入感弱。
- 方案 B：Blender 里把前柜向北移 ~0.6m，通道拓宽至 ≥0.9m，玩家真实站进吧台内侧。代入感强；代价是场景改动＋吧台凳随移＋灯光/视角复查。


### 2026-11-06 Arnold 决策

**选定方案 B：拓宽通道。** 补充事实：模型中 0.32m 的通道是建模偏差，真实店铺的吧台内侧宽得多（可放咖啡机等设备、容许两人通过）。改造目标：前后柜台通道 ≥ 1.2m（两人通行），即前柜（含台面收银、上方 Bar_Rack、吧凳、吧台吊灯）整体向北移约 0.9m。改动在实施阶段（竖切）执行，属一次性场景修正。

## Answer

吧台九工位布局定案：

1. 后柜台面（西→东）：磨豆×2＋压粉 → 浓缩咖啡机 → 杂物区（重整）→ 东段 1.8m 新增茶罐架、注水/茶壶位、托盘存放
2. 前柜台面：点单/收银（x≈3.06）、西段兼出杯台
3. 搅拌工位：后柜杂物区重整后腾出，搅拌棒归位点挂后柜
4. 玩家站位：吧台内侧，通道拓宽至 ≥1.2m（前柜北移 ~0.9m，吧凳/Bar_Rack/吊灯随移）
5. 顾客动线：主入口（右下，x≈8.6）→ 前台点单，验证顺畅
