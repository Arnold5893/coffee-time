# 06 · 吧台灰盒布局方案

Type: prototype
Status: open
Blocked by: 02

## Question

在 Unity 灰盒中排布吧台九个工位（设计方案 12.3：点单/收银位、浓缩咖啡机位、磨豆机位、茶罐架、注水/茶壶位、出杯台、搅拌工位、托盘存放点、玩家站位与移动路径），验证：

- 真实尺寸下各工位间距是否顺手（对照平面图与照片）
- 玩家站位与原地近景镜头的取景范围是否覆盖全部工位
- 茶罐架、进度条显示位置的空间预留
- 若 02 结论为"废弃重建"，本票同时承担全店灰盒的方块布局验证

输出：灰盒场景截图＋布局定案（含任何对设计方案 12.3 的调整建议）。

## 完成标准

灰盒布局经 Arnold 确认；调整建议（如有）记录；登记到 map。
